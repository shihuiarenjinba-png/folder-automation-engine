# Folder Automation Engine — Privacy Policy

Status: Store preparation text. A public URL can be assigned later if the submission form requires one.

Folder Automation Engine is a Windows desktop application that organizes local files using user-defined filename rules. It can preview, copy, or move matching files and can optionally monitor a user-selected local folder while the application is running.

The application may access user-selected folder paths, file names, sizes, timestamps, file-system metadata, and file contents required for copy or move operations. Processing state is stored locally to help prevent duplicate operations.

The core workflow is local-only and does not require a hosted cloud service. If the user selects a cloud-synchronized folder or network drive, that location is governed by the corresponding provider or network environment.

The user chooses the root folder, rules, destinations, and whether to perform a one-time operation or optional watcher. The guided UI requires a successful Dry Run and explicit confirmation before live operations. Existing destination files are not overwritten by default.

Configuration and processing state remain on the user's device until the user removes them.
